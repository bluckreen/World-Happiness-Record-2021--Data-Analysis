Global Happiness Data Analysis 2021

📌 Overview

This project focuses on analyzing global happiness data to understand the factors that influence a country’s overall well-being. The dataset includes 149 countries and various socio-economic indicators.

👩‍💻 Creator
Saliha Jibin P

🎯 Objective
The main goal of this project is to:
* Analyze how different factors affect happiness levels
* Identify the most impactful variables
* Explore patterns and trends across countries and regions
* Build foundational skills in data analysis and visualization

📊 Dataset Details
* Total Countries: 149
* Total Features: 20
* Data Type:
    - 18 Numerical Columns
    - 2 Categorical Columns
* Target Variable: Ladder Score (Happiness Score)

🔍 Features Included
* GDP per capita
* Social support
* Healthy life expectancy
* Freedom to make life choices
* Generosity
* Perceptions of corruption
* Dystopia-based indicators

⚙️ Methods Used
* Data Cleaning (ensuring consistency and usability)
* Univariate Analysis (distribution of individual variables)
* Bivariate Analysis (relationships between variables)
* Data Visualization (bar plots, scatter plots, pair plots, etc.)

📈 Key Insights
* Happiness scores show moderate variation across countries
* GDP, social support, and life expectancy strongly influence happiness
* Most variables have symmetric distributions with low skewness
* Life expectancy shows bimodal distribution, indicating two country groups
* Generosity and corruption show higher variability
* Presence of outliers highlights global inequality
* Dystopia baseline remains constant and helps in comparison

🛠️ Tools & Libraries
* Python
   - Pandas
   - Matplotlib
   - Seaborn
* Jupyter Notebook

📌 Conclusion

Happiness is a multi-dimensional concept influenced by economic, social, and health-related factors, while this project builds essential skills in data analysis and interpretation.
